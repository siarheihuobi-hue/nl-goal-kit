# NL GOAL Kit

Методология управления нейрокомандами через цели и проверяемые результаты. Разработка NeuroLab.

**v0.3 — 26.11.2026.** Кандидат на релиз: практическая проверка ещё не завершена.

Владелец определяет что и зачем; команда определяет как. Методология не требует конкретной модели, агента или перестройки архитектуры.

Передайте агенту эту команду для установки, обновления или проверки. Это текстовое поручение ИИ-агенту, а не команда оболочки:

> Внедри или обнови NL GOAL по единому протоколу из https://github.com/siarheihuobi-hue/nl-goal-kit/releases/tag/v0.3. Определи состояние моей среды и выбери нужный маршрут. Прочитай полный комплект одной зафиксированной версии, выполни необходимые безопасные действия, сохрани мои адаптации и данные, проверь результат и предоставь доказательства и способ отката. При конфликте, существенном риске или нехватке полномочий остановись и спроси меня. Не объявляй блокер успешной установкой.

Ссылка на выпуск v0.3 заработает после его публикации. До этого для испытания укажите вместо неё доступный локальный комплект, зафиксированный конкретным коммитом. Агент фиксирует тег или коммит до чтения и не смешивает версии. Команда не отменяет ограничений среды и не требует подписки.
